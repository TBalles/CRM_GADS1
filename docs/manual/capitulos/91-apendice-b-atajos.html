Todo el sistema se puede usar con el teclado. El elemento que tiene el foco siempre se ve con un borde de color, y después de cerrar un panel, un menú o una confirmación, el foco vuelve al botón que lo abrió.

En cualquier pantalla

TeclasQué hacen
Ctrl + K (Mac: ⌘ + K)Abre la búsqueda global. Adentro, ↑ ↓ se mueven entre resultados, Enter abre el resaltado y Esc la cierra.
Tab / Shift + TabPasar al campo o botón siguiente o anterior. La primera vez que apretás Tab en una pantalla aparece «Saltar al contenido», para no recorrer todo el menú. La búsqueda global, los paneles y las confirmaciones mantienen el foco adentro hasta que los cerrás.
EscCierra lo que esté arriba: un menú, un calendario, un panel lateral, una confirmación, la búsqueda global o la vista previa. Si hay un menú abierto dentro de un panel, cierra solo el menú. Mientras se está guardando, no cierra.
Enter / EspacioAprietan el botón o el enlace que tiene el foco.
F5Recargar la pantalla.
Ctrl + PImprimir. Para el presupuesto es mejor el botón Imprimir / Guardar PDF (renueva el logo).

En listas, menús y pestañas

TeclasQué hacen
↑ ↓ en Empresas o ContactosCon el foco en la tabla y una pantalla ancha, eligen la fila de arriba o de abajo y la vista previa la sigue. Enter sobre el nombre abre la ficha; Esc cierra la vista previa.
Menú ⋮ y filtrosEnter, Espacio o ↓ lo abren; ↑ ↓, Inicio y Fin se mueven; escribir las primeras letras salta a esa opción; Enter elige; Esc o Tab lo cierran.
Listas desplegablesIgual que los menús; las que tienen buscador filtran mientras escribís.
Pestañas y secciones← → (o ↑ ↓ en la columna de Configuración) se mueven entre pestañas; Enter o Espacio abren la elegida.
Selectores como «Tablero | Lista» o el filtro de AlertasLas flechas cambian la opción.
Fila de una ventaEnter o Espacio sobre el nombre del cliente despliegan o pliegan el detalle.

En los campos de fecha

TeclasQué hacen
Escribir + EnterToma la fecha escrita (dd/mm/aaaa) sin enviar el formulario. También se toma al salir del campo.
Alt + ↓Abre el calendario.
← → / ↑ ↓En el calendario, un día o una semana.
Inicio / FinLunes o domingo de esa semana.
RePág / AvPágMes anterior o siguiente (con Shift, un año).
Enter / EspacioElige el día.
EscCierra el calendario y deja el foco en el campo (el siguiente Esc cierra el panel, si estás en uno).

Mouse y pantalla táctil

GestoQué hace
Arrastrar una tarjetaEn el tablero de oportunidades, cambia la etapa. No funciona con el dedo: en el celular (o con el teclado) usá Cambiar etapa del menú ⋮ de la tarjeta.
Clic en el nombreEn las listas, abre la ficha o el detalle.
Clic en la filaEn Empresas y Contactos (pantalla ancha), abre la vista previa. En Ventas, despliega el detalle.
Ctrl + clic o botón del medioEn nombres, paginación y vista previa, abre en otra pestaña (son enlaces de verdad).
Menú ⋮Reúne las acciones de una fila o una tarjeta.
Tocar afuera de un panelLo cierra (sin guardar).
Deslizar de costadoEn el celular, mueve el tablero de oportunidades entre columnas, las pestañas de una ficha y la hoja del presupuesto a tamaño real.

Si usás mucho el sistema, aprendé Ctrl + K primero: reemplaza a casi todo el menú. Escribí las primeras letras de una empresa, de una oportunidad o de un producto y entrá directo.

Teclado

TeclasQué hacen
Ctrl + K (Mac: ⌘ + K)Abre la búsqueda global desde cualquier pantalla.
↑ ↓En la búsqueda global, moverse entre resultados. En un menú desplegable, entre opciones.
EnterEn la búsqueda global, abrir el resultado resaltado.
EscCierra la búsqueda global, un panel lateral, un cuadro de confirmación o un menú abierto. Mientras se está guardando, no cierra.
Tab / Shift + TabPasar al campo o botón siguiente o anterior. La búsqueda global y los paneles mantienen el foco adentro hasta que los cerrás.
F5Recargar la pantalla.
Ctrl + PImprimir. Para el presupuesto es mejor el botón Imprimir / Guardar PDF (renueva el logo).

Mouse y pantalla táctil

GestoQué hace
Arrastrar una tarjetaEn el tablero de oportunidades, cambia la etapa. No funciona con el dedo: en el celular usá Cambiar etapa del menú ⋮ de la tarjeta.
Clic en el nombreEn las listas, abre la ficha o el detalle.
Menú ⋮Reúne las acciones de una fila o una tarjeta.
Tocar afuera de un panelLo cierra (sin guardar).
Deslizar de costadoEn el celular, mueve el tablero de oportunidades entre columnas y la hoja del presupuesto.

Si usás mucho el tablero, aprendé Ctrl + K primero: reemplaza a casi todo el menú. Escribí las primeras letras de una empresa, de una oportunidad o de un producto y entrá directo.
